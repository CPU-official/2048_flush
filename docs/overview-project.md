# 2048 (행사용)

**목적**: 행사 현장에서 2048 게임을 제공하는 **Windows + macOS 전용 Electron PC 앱**. 웹/모바일은 지원하지 않는다.

**핵심 재미**: 원래 2048은 시간 제한이 없지만, 이 게임은 **한 수마다 제한 시간**이 있고 갈수록 짧아진다. 화려한 VFX가 핵심이다.

관련 문서: 서버/멀티/랭킹은 [networking.md](networking.md), 기술 선택과 폴더 구조는 [tech-stack.md](tech-stack.md).

## 핵심 기능

- 시작 화면 (게임 플레이, 대결, 랭킹, 설정)
- 게임 화면 (수당 제한 시간, VFX)
- 대결 (LAN에서 1대1, 같은 시드로 누가 더 높은 점수를 내는지 겨룸)
- 랭킹 (게임이 끝나면 닉네임 + 4자리 비밀번호로 기록, 서버 PC에 중앙 저장)
- 설정 (서버 관리자용 + 이 PC의 VFX on/off)

## 계정 규칙 (닉네임 + 비밀번호)

- 닉네임: 앞뒤 공백 제거 후 1~10자(`NICKNAME_MAX`), 대소문자 구분. (대결은 닉네임만 필요하고 비밀번호는 묻지 않는다.)
- 비밀번호: **숫자 4자리 문자열**(`^\d{4}$`). 숫자 타입이 아니라 문자열로 저장한다 (`0123`이 `123`이 되지 않게). 클라이언트와 서버 모두 검사한다.
- 처음 쓰는 닉네임이면 그 비밀번호로 등록된다. 이미 있는 닉네임이면 비밀번호가 같아야 한다. 다르면 거부된다.
- 계정은 별도 가입 없이 첫 기록 제출 시 만들어진다.

## 화면

### 시작 화면

- 좌우 2단 구성.
  - 왼쪽 상단: 로고. 네온 그린 한 색으로 채운 비스듬한 배지(SVG, `src/ui/ui.ts`)에 "2048"을 배경색으로 음각한 납작한 스타일. 글로우/그림자/그라데이션은 쓰지 않는다. 색은 앱 팔레트(`--neon`, `--bg`)를 따른다
  - 왼쪽 하단: 게임 플레이, 대결, 랭킹, 설정 버튼 (서버에 연결되지 않으면 "대결"은 비활성)
  - 오른쪽: 가상의 2048 게임 플레이(데모). AI를 새로 만들지 않고, **미리 기록한 이동 로그를 `core`로 재생**한다 (로그 파일: `src/assets/demo-log.json`).
    - 로그 형식: `{ "seed": 시드, "moves": "lrud를 이어 붙인 문자열" }`. 로그의 모든 수는 보드를 바꾸는 유효한 수다.
    - 재생: `DEMO_STEP`(0.35초)마다 한 수씩 두고, 끝나면 마지막 판을 `DEMO_END_PAUSE`(2.5초) 보여 준 뒤 처음부터 다시 재생한다. 시작 화면일 때만 보이고, 게임을 시작하면 숨긴다. 창이 작으면 보드를 줄여 오른쪽 절반의 가운데에 맞춘다.
    - 데모는 VFX 설정과 무관하게 타일 이동/머지 연출만 쓴다 (파티클, 튕김, 비네팅 없음).
    - `core` 규칙이나 RNG가 바뀌어 로그가 어긋나면 `src/game/demo.test.ts`가 깨진다. 그때는 로그를 새로 기록한다 (앱에는 로그를 만드는 AI를 넣지 않는다).
- 서버 연결 상태(연결됨/끊김/대기 중 N건)를 화면 오른쪽 위에 표시한다. 시작 화면뿐 아니라 모든 화면에서 보인다 ([networking.md](networking.md) "오프라인 큐").
- `/` 키로 슬래시 커맨드 입력창을 연다 (서버 모드 PC에서만 운영 명령이 동작). 명령 목록과 동작은 [networking.md](networking.md) "슬래시 커맨드".

### 랭킹 화면

- 가운데 팝업. 상단 탭 2개. 시작 화면의 "랭킹" 버튼과 게임 오버 후 팝업의 "랭킹" 버튼으로 연다 (처음에는 전체 순위 탭).
  - **전체 순위**: 닉네임별 최고 점수 순. 한 닉네임당 한 줄.
  - **개인 기록**: 현재 계정(닉네임)의 게임별 기록을 점수 높은 순으로. 계정이 없으면 "기록 후 확인할 수 있어요" 안내. 종료하면 계정이 비워지므로 시작 화면에서 열면 항상 이 안내가 보이고, 실제 기록은 게임 오버 후 팝업에서 열었을 때 보인다.
- 데이터는 서버에서 받아온다. 서버에 연결되지 않으면 빈 목록 대신 "서버 연결 안 됨"을 표시한다. 기록이 하나도 없으면 "아직 기록이 없어요".
- 한 줄에 순위, 닉네임, 점수를 보여 준다. 상위 `RANK_TOP`(50)줄까지. 아래 "닫기" 버튼으로 닫는다.
- 랭킹은 **싱글 플레이 기록만** 다룬다. 1대1 대결 결과는 반영하지 않는다.

### 게임 플레이 화면

**보드 규칙**

- 4x4 보드. 게임은 타일 2개로 시작한다.
- 유효한 수마다 빈칸 하나에 새 타일이 생긴다: 2가 90%, 4가 10% (`core`의 `FOUR_CHANCE`).
- 한 수에 한 타일은 한 번만 머지된다. 미는 쪽에 가까운 쌍이 먼저 머지된다 (`2 2 2` → 오른쪽으로 밀면 `2 4`).
- 점수는 머지로 만들어진 타일 값의 합이다.
- 2048을 만들어도 게임은 끝나지 않는다. 더 움직일 수 없거나(스턱) 시간이 끝나야 게임 오버다.

**입력**

- 방향키 또는 WASD. WASD는 물리 키 위치(`KeyboardEvent.code`) 기준이라 한글 입력기나 Caps Lock 상태에서도 동작한다.
- 키를 누르고 있을 때의 자동 반복 입력은 무시한다 (한 번 누르면 한 수).

**제한 시간 규칙**

- 한 수마다 제한 시간이 있다 ("무한의 계단" 방식).
- 제한 시간은 **S자(시그모이드) 곡선**으로 서서히 줄어든다.

  ```
  제한시간(n) = 시작값 - 최대감소값 × sigmoid(기울기 × (n - 중간수))
  sigmoid(x) = 1 / (1 + e^-x)
  ```

  - `n` = 이번 게임에서 지금까지 한 **유효한 수**의 횟수 (보드가 변하지 않는 입력은 수로 세지 않고 타이머도 리셋하지 않는다).
  - 초기값: 시작값 3.0초, 최대감소값 2.0초(최소 1.0초), 중간수 40, 기울기 0.1.
  - 위 4개 값은 **서버 관리자가 설정**하고, 서버가 모든 클라이언트에 내려준다. 바뀐 값은 **다음 게임부터** 적용된다 (진행 중인 게임은 그대로).
  - 서버에 연결되지 않았으면 마지막으로 받은 값, 없으면 위 초기값을 쓴다.
- 타이머는 직전 이동이 반영된 즉시 시작한다. 첫 수는 게임 시작 직후부터.
- 급박한 효과를 위해 **타이머가 0이 돼도 0.15초 안에 움직이면 살린다.** 이 유예는 클라이언트 로컬 시계로 판단한다.
- 시간이 끝나면(유예 포함) 게임 오버. 사유는 `timeout`으로 기록한다 (`gameover`의 `reason`, [networking.md](networking.md) 참고).
- 타이머는 `core` 밖(`src/game/`)에 둔다. `core`는 시간에 의존하지 않는다.

**연출**

- 이동할 때마다 이동 방향으로 보드가 살짝 튕긴다.
- 시간 바가 줄어들수록 비네팅이 서서히 짙어지고 색이 붉어진다.
- **머지 연출은 값이 클수록 강하다.** 머지 파티클 수는 `6 + 2 × log2(값)`개다. 한 수에 머지가 여러 개면 가장 큰 값으로 아래 연출을 **한 번만** 한다.
  - 화면 흔들림: 128 이상부터. 값이 두 배가 될 때마다 4px씩 커지고 최대 24px (`SHAKE_FROM`, `SHAKE_STEP`, `SHAKE_MAX`).
  - 화면 번쩍임: 512 이상부터. 그 타일 색으로 투명도 0.1에서 시작해 두 배마다 0.1씩 커지고 최대 0.4 (`FLASH_FROM`, `FLASH_STEP`, `FLASH_MAX`).
  - 최고 타일 갱신: 이번 게임에서 지금까지 나온 가장 큰 타일을 넘는 머지가 `RECORD_FROM`(64) 이상이면, 그 값으로 머지된 타일(같은 값이 한 수에 둘이면 둘 다)의 파티클을 3배(`RECORD_BURST`)로 늘리고 번쩍임은 최소 `RECORD_FLASH`(0.15)로 한다. 같은 값은 갱신이 아니다. 새 UI 요소(문구 등)는 쓰지 않는다.
  - 점수 스택(`+점수`): 점수가 클수록 더 크게 튀어오르고 빛난다 (`+4`는 기본, `+1024` 이상이 최대).
  - 파티클 수에는 상한(`MAX_PARTICLES` 200)이 있고, 필터는 쓰지 않는다. 설정 화면에서 VFX를 끄면 파티클, 튕김, 흔들림, 번쩍임이 모두 빠진다 (점수 스택 강조는 HUD라 그대로).

**레이아웃**

- 중앙에 2048 보드.
- 하단에 시간 바 (남은 시간이 왼쪽, 사라진 부분이 오른쪽).
- 보드 상단 좌우에 HUD: 이전 최고 점수, 점수 스택(한 번에 올린 점수), 이번 점수, 닉네임.
  - 이전 최고 점수: 계정이 있으면 그 닉네임의 서버 기록 최고값, 없으면 `--`.
- 위에 없는 UI 요소가 필요하면 추가 전에 먼저 허가를 받는다.

**게임 종료 흐름**

1. 게임 오버.
2. 계정이 없으면 닉네임 + 비밀번호 입력창 (이번 점수를 함께 보여 주고, 비밀번호는 가려서 입력한다). 형식이 틀리면 서버에 보내지 않고 오류 문구를 띄운다. 서버가 비밀번호 불일치로 거부하면 오류 문구를 띄우고 입력창으로 돌아간다 (닉네임은 남기고 비밀번호만 비운다). **"기록 안 하고 종료"** 버튼으로 입력 없이 시작 화면으로 나갈 수 있다 (기록은 남지 않는다).
3. 기록 제출 (서버가 없으면 오프라인 큐에 저장).
4. **계속 플레이 / 랭킹 / 종료** 팝업. 종료 사유("시간 초과" 또는 "더 움직일 수 없음")와 최종 점수를 함께 보여 준다.
   - 랭킹: 랭킹 화면을 연다. 계정이 있는 상태라 "개인 기록" 탭에서 자기 기록을 볼 수 있다. 닫으면 이 팝업으로 돌아오고 계정은 유지된다. 보는 동안에도 아래 5번의 무입력 종료는 적용된다.
   - 계속 플레이: 같은 계정으로 새 게임. 이후 게임 오버에는 닉네임 입력창이 뜨지 않고 바로 제출 후 같은 팝업이 뜬다.
   - 종료: 계정 정보를 메모리에서 비우고 시작 화면으로.
5. **60초(`IDLE_LOGOUT`) 동안 입력이 없으면 종료와 동일하게 처리한다** (행사장 공용 PC에서 다음 방문자가 앞사람 계정으로 플레이하는 것을 막는다).

### 대결 화면 (1대1)

랭킹과 무관한 별도 모드다. 같은 시드의 보드를 두 사람이 동시에 플레이하고, **더 높은 점수를 낸 쪽이 이긴다.**

**진행**

1. 시작 화면에서 "대결" → 닉네임 입력 (싱글 계정이 있으면 그 닉네임을 그대로 쓴다) → "대기 중…" 화면 (취소 가능).
2. 서버가 먼저 기다리던 사람과 **선착순으로 둘씩 짝**을 지어 준다 (방 코드 없음). 서버 PC 본인도 참가할 수 있다.
3. 상대가 정해지면 닉네임을 양쪽에 보여 주고 3초(`MATCH_COUNTDOWN`) 카운트다운 후 **동시 시작**한다.
4. 보드와 규칙은 싱글과 같다 (수당 제한 시간 포함). 제한 시간 설정은 시작 시점의 값으로 두 사람에게 똑같이 적용된다.
5. **종료**: 두 사람의 게임이 모두 끝나면(스턱 또는 시간 초과), 또는 대결 시간 상한 180초(`MATCH_TIME_LIMIT`)가 되면 끝난다. 상한에 도달하면 그 시점의 점수로 가린다.
6. 점수가 높은 쪽 승리, 같으면 무승부. 한쪽만 먼저 끝나면 그 점수가 상대 화면에 "목표 점수"로 남고, 남은 쪽은 자기 게임이 끝날 때까지 계속한다.
7. 결과 팝업(승/패/무승부, 양쪽 점수)에서 "다시 대결 찾기" 또는 "시작 화면"을 고른다. 결과는 랭킹에 반영하지 않는다.

**레이아웃**

- 화면을 좌우로 나눠 **왼쪽은 내 보드, 오른쪽은 상대 보드** (같은 크기). 위에 각자 닉네임과 점수, 아래에 각자의 시간 바.
- 상대 보드는 서버가 중계한 입력을 로컬에서 재생해 그린다. 내 보드는 풀 VFX, 상대 보드는 경량 VFX만 쓴다.
- 가운데에 점수 차이(`+320`처럼 앞선 쪽 방향으로 표시)와 남은 대결 시간.
- 상대가 먼저 끝났으면 상대 보드에 "종료" 표시와 최종 점수를 띄운다.

**화면 구현 메모** (`src/ui/match.ts`, `src/main.ts`)

- "대결" 버튼은 서버에 연결돼 있을 때만 켜진다 (연결이 끊기면 다시 꺼진다). 시작 화면에서는 싱글 계정이 항상 비어 있으므로 닉네임을 **매번 입력**한다 (`NICKNAME_MAX`자 이내, 앞뒤 공백 제거). 입력한 닉네임은 시작 화면으로 돌아가면 지운다.
- 닉네임 입력 → "상대 찾기" → 같은 팝업이 "상대를 기다리는 중…"(취소 버튼만)으로 바뀐다. 대기 중에 서버 연결이 끊기면 시작 화면으로 돌아간다.
- 짝이 지어지면 대결 화면으로 바뀌고 카운트다운(큰 숫자)이 뜬다. 카운트다운 중 입력은 무시한다. 시작하면 숫자가 사라지고 가운데에 남은 대결 시간(`분:초`)이 보인다.
- 화면 배치: 보드는 각각 화면 절반의 가운데에 같은 크기로 놓고, 창이 작으면 함께 줄인다. 닉네임과 점수는 보드 위(왼쪽 내 것, 오른쪽 상대 것), 시간 바는 보드 아래, 가운데 위에 점수 차이(`◀ +320` / `+320 ▶`, 같으면 `0`)와 남은 시간이다.
- **상대 시간 바**는 상대 화면의 실제 타이머가 아니라 상대 입력이 이쪽에 도착한 시각부터 줄어드는 값으로 **짐작해서** 그린다 (상대가 끝나면 0). 상대 보드의 경량 VFX는 타일 이동/머지 연출만이다 (파티클, 튕김, 흔들림, 번쩍임 없음).
- 내가 끝나거나 상대가 끝나면 그 쪽 점수 옆에 "종료"를 띄운다. 내 보드와 시간 바 비네팅은 싱글과 같다.
- 결과 팝업: 승리/패배/무승부와 양쪽 점수. 대결 시간 상한으로 끝났으면 "대결 시간이 끝났어요", 상대가 돌아오지 않아 이겼으면(부전승) "상대가 돌아오지 않아 승리했어요"를 덧붙인다. 부전승일 때는 서버 점수 대신 이 화면의 두 점수를 보여 준다. "다시 대결 찾기"는 같은 닉네임으로 바로 대기에 들어가고, "시작 화면"은 대결을 정리하고 돌아간다.
- 내 연결이 끊기면 가운데에 "재접속 중…"을 띄우고 보드를 멈춘다. 15초 안에 돌아오면 두 보드를 복원해 이어가고, 못 돌아오면 시작 화면으로 돌아간다 (결과 화면 없음). 상대가 끊겼을 때는 같은 자리에 "상대 재접속 대기 중…"을 띄운다.
- 대결 중에는 싱글의 60초 무입력 종료를 적용하지 않는다.

**끊김 처리**

- 상대 연결이 끊기면 "상대 재접속 대기 중…"을 표시하고 15초(`RECONNECT_WAIT`) 기다린다. 돌아오면 이어서 진행하고, 돌아오지 않으면 남은 사람이 **부전승**한다.
- 내가 끊겼다가 돌아오면 서버가 입력 로그를 다시 보내 보드를 복원한다 ([networking.md](networking.md) 참고).

### 설정 화면

일반 사용자용 설정은 없다. 서버 관리자용 설정만 둔다. 클라이언트 모드와 서버 모드에서 보이는 항목이 다르다.

**공통 (이 PC)**

- VFX on/off (이 PC의 `config.json`에만 저장, 저사양 PC용). 끄면 **머지 파티클, 보드 튕김, 화면 흔들림, 화면 번쩍임**을 생략한다. 타일 이동/머지 트윈과 비네팅은 게임을 읽는 데 필요해 그대로 둔다.

**클라이언트 모드**

- 서버 주소(`IP:포트`) 입력과 "접속" 버튼 (비우고 누르면 접속 해제), 연결 상태 표시, "연결 테스트" 버튼
- "이 PC를 서버로 쓰기": 포트 입력과 "서버 시작" 버튼. 시작하면 이 PC가 서버 모드가 되고 화면이 아래 서버 모드 항목으로 바뀐다.

**서버 모드 (호스트 PC)**

- 서버 주소(`IP:포트`) 크게 표시, "서버 중지" 버튼 (중지하면 클라이언트 모드로 돌아간다). 포트는 서버를 시작할 때 정한다.
- 수당 제한 시간 4개 값 (시작값, 최대감소값, 중간수, 기울기). 저장 시 검증: 시작값 > 0, 최솟값(시작값 - 최대감소값) ≥ 0.5초. 검증에 걸리면 저장하지 않고 이유를 보여 준다. 바뀐 값은 접속 중인 클라이언트에 바로 전달되고 **다음 게임부터** 적용된다. 빈 칸이나 숫자가 아닌 값은 거부한다.
- 랭킹 관리: "CSV 내보내기"(저장된 파일 경로를 화면에 보여 준다), "랭킹 초기화"(버튼을 **두 번** 눌러야 실행되고, 지우기 전에 자동 백업한다. 기록과 닉네임이 모두 지워진다). 파일 형식과 위치는 [networking.md](networking.md) 참고
- 사용자 관리: 닉네임 목록(문자 코드 순, 스크롤), 줄마다 새 비밀번호 입력 + "변경"(숫자 4자리), "삭제"(**두 번** 눌러야 실행, 그 닉네임의 기록도 함께 삭제, 백업 없음). **현재 비밀번호는 화면에 표시하지 않는다.**
- 설정 화면의 버튼과 슬래시 커맨드는 **같은 서버 함수**를 호출한다 (규칙을 한 곳에만 구현).

## 디자인 가이드

- 에픽 게임즈 게임 스타일을 참고
- 굵은 폰트를 과감하게 사용
- 프레임 내부에 패턴을 조합 (옅은 사선 패턴)
- 버튼은 둥글게 (알약 모양)
- 포인트 컬러는 네온 그린 (`#39ff14`)
- 바탕은 색이 섞이지 않은 **무채색 다크 톤**. 패널과 보드는 큰 둥근 모서리, 1px 옅은 테두리, 깊은 그림자로 띄운다.
- 주 버튼은 위에서 빛을 받는 광택 그라디언트와 바깥 글로우를 준다. 보조/비활성 버튼은 어두운 면에 옅은 테두리만 둔다.
- 포인트 컬러는 주 버튼, 점수, 시간 바, 높은 값 타일에만 쓴다. 낮은 값 타일(2, 4)은 회색이다.
- 색과 수치의 기준은 `src/ui/style.css`의 `:root` 변수다.

## 구현 순서

1. `core` (보드, 이동, 머지, 점수, 시드 RNG) + 리플레이 테스트
2. 싱글 게임 화면 + 기본 VFX + 타이머(`src/game/`)
3. 서버(랭킹 저장, ws) + 클라이언트 접속 + 랭킹 화면 + 계정 흐름
4. 오프라인 큐, 연결 상태 표시
5. 설정 화면(서버 관리자) + 슬래시 커맨드
6. 시작 화면 데모 재생, VFX 확장
7. 1대1 대결 (매칭, 시드/입력 중계, 대결 화면)
